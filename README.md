# Academic Notes

Mac 上的中英学术语音笔记。打开应用、允许麦克风访问后，悬浮窗会显示原语言字幕。点击「结束」将已定稿文字保存到本机，并在自己的飞书云盘创建一篇带时间戳的文档。音频在内存中处理。

## 使用

- 录音或暂停时，点击顶部工具栏中的标题即可改名。按回车、移开焦点或结束记录时保存。本地文件名包含标题和会话标识，飞书文档采用填写的标题。
- 顶部的图钉可随时切换字幕窗口置顶。首次打开时默认置顶，之后会记住上次的选择。
- 「暂停」会提交当前句，「继续」接着记到同一篇。「标重点」（⌘B）会在当前时间插入 ★。
- 在齿轮设置中选择转写引擎。默认本地模型为 Qwen3-ASR 1.7B（约 2.2 GB），轻量模型为 0.6B（约 840 MB）。首次选用并启动时下载，之后可离线转写。
- 选择「云端 API · 阿里云百炼」时，选对应地域，填入该地域的 API Key 并点「保存」。密钥存入 macOS 钥匙串。Workspace ID 可用于连接业务空间专属域名。云端模式会将麦克风音频发给百炼的实时转写服务，按账户用量计费。[百炼模型说明](https://help.aliyun.com/zh/model-studio/qwen-audio-3-1-asr-flash-streaming)
- 引擎和课题术语在下次开始或继续记录时生效。术语可填英文缩写、人名等，用逗号分隔。飞书文件夹 token 可留空，默认保存到个人云盘。
- 点「打开最近的飞书笔记」查看最近上传的笔记。同步失败时会出现「重试同步」，网络恢复或下次启动时也会自动补传。本地文字可在「本地笔记」中查看。
- 应用采集系统默认麦克风。临时字幕和定稿都会把中文转成简体，英文保留原文。本地笔记与飞书使用同一份定稿。

## 从源码运行

适用于 Apple 芯片 Mac、macOS 15 及以上。安装 Xcode 命令行工具、uv 和已配置的飞书官方 lark-cli。首次连接飞书可运行 `lark-cli auth login --domain docs --domain drive`。

```sh
./build.sh
open "build/Academic Notes.app"
```

构建会把 Python 运行时装在用户的 Application Support/AcademicNotes 下。本地转写通过 MLX 运行 8 位量化模型，暂停或结束后释放模型内存。
